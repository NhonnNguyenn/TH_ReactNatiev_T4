# TypeScript OOP – 30 Câu

## Cách dùng nhanh

```bash
# 1) Giải nén thư mục, mở folder bằng VSCode
npm install
npm run build
node dist/index.js   # chỉ để kiểm tra build OK (in ra 1 dòng)

# Chạy thử từng câu (cách nhanh nhất)
# Cài ts-node cho chạy trực tiếp .ts (tùy chọn)
npm i -D ts-node
npx ts-node src/q1.ts
npx ts-node src/q2.ts
# ... tương tự tới q30.ts
```

- Mỗi bài nằm trong `src/q{1..30}.ts` (độc lập, có test console riêng).
- Commit từng câu:

```bash
git add .
git commit -m "Câu 1: Person"
git push
```
