
# Async Exercises (TypeScript) - Week02
## Hướng dẫn sử dụng 
   ```bash
   npm install
   ```
 Chạy từng bài bằng `ts-node`:
   ```bash
   npx ts-node src/exercises/ex1.ts
   ```
   hoặc chạy nhiều bài:
   ```bash
   npx ts-node src/exercises/ex1.ts && npx ts-node src/exercises/ex2.ts
   ```
